# MA03. Logic, sets and proofs

| Track | Stage | Depends on | Needed by |
|---|---|---|---|
| Mathematics | 1. Foundations | MA02 | MA04, MA07, MA08, MA12, MA13 |

## Why this module

Research papers state results as definitions, theorems and proofs, and use the notation of sets and quantifiers on every page. Proving that a derivation is right (or finding why it is wrong) is what separates understanding an algorithm from copying it. This module teaches how to read and write mathematics.

## Objectives

After this module, you can read any mathematical statement written with quantifiers and set notation, negate it correctly, and write rigorous proofs with the standard techniques.

## Competences evaluated

1. Build the truth table of a compound proposition; recognize tautologies and equivalent propositions (including De Morgan's laws).
2. Distinguish an implication from its converse and its contrapositive; use "necessary" and "sufficient" correctly.
3. Read and write statements with quantifiers (∀, ∃), and negate them correctly, including nested quantifiers.
4. Use set notation (∈, ⊂, ∪, ∩, complement, difference, ∅, ℕ, ℤ, ℚ, ℝ, intervals) and compute set operations, Cartesian products and power sets.
5. Read and write sums and products with ∑ and ∏, change the index, split and combine sums, and compute classic sums (1 + 2 + … + n, geometric sums).
6. Decide whether a function between sets is injective, surjective or bijective, compute compositions and inverses.
7. Recognize order relations and equivalence relations, and describe equivalence classes (for example remainders modulo n).
8. Write a direct proof, a proof by contrapositive, a proof by contradiction and a proof by induction (simple and strong).
9. Disprove a statement with a counterexample.
10. Find the error in a flawed proof.

## Notions, in learning order

1. **Propositions and connectives**: and, or, not, implication, equivalence, truth tables, tautologies, De Morgan's laws.
2. **Implication**: converse, contrapositive, necessary and sufficient conditions, "if and only if".
3. **Quantifiers**: universal and existential, order of nested quantifiers, negation rules.
4. **Sets**: membership, inclusion, equality, operations, number sets, intervals, Cartesian product, power set, cardinality of finite sets.
5. **Sum and product notation**: ∑ and ∏, index changes, double sums, telescoping sums, classic closed forms.
6. **Functions between sets**: domain, codomain, image, preimage, injective, surjective and bijective functions, composition, inverse.
7. **Relations**: reflexivity, symmetry, antisymmetry, transitivity, order relations, equivalence relations and classes.
8. **Proof techniques**: direct proof, contrapositive, contradiction, cases, induction (simple and strong), counterexamples.
9. **Writing proofs**: structure, definitions first, one claim per step, common mistakes (assuming the conclusion, wrong negation, induction without base case).

## Practice

- Truth tables and negations of statements taken from real definitions (limit of a sequence, continuity, injectivity).
- A proof every day: classic results (the sum 1 + … + n, divisibility statements, √2 irrational, infinitely many primes) rewritten without looking.
- Reading exercise: definitions and theorem statements extracted from a machine learning paper, rewritten in plain language.
- Once IN02 is validated: a truth-table generator for any formula, and set operations implemented on lists.

## Evaluation format

One written session, about 2 hours: exercises on every competence, 4 proofs to write (one per technique), one flawed proof to correct. Pass mark 100 %.
