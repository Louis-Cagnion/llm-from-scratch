# 2026-10-04

## Session 1: project kickoff and the two learning plans

**Goal.** Frame the project and design the complete path, from zero to a modern language model built without any library.

**What was done.**
- Defined the from-scratch policy. The platform (hardware, operating system, compilers, CUDA drivers) may be used. Every algorithm is written by hand, first in pure Python, then in C or CUDA where speed matters. Even `math`, `random`, `re`, `json`, `zlib` and `ssl` are rewritten by hand.
- Designed the prerequisites plan: 49 modules in four tracks (mathematics, programming, systems, method). The plan is followed in seven stages, from the most fundamental to the least.
- Wrote the detailed file of each of the 49 modules: objectives, competences evaluated, notions, practice, evaluation format and references.
- Designed the LLM plan: 70 modules in fourteen parts. A first working text model I can chat with comes before any extension. The extensions follow: inference engine, modern architectures, scaling out, harness and applications, advanced post-training, then multimodality (image understanding and image generation).
- Set up the repository, the README and the instructions for the teaching sessions.

**How.** I settled each open question before writing: languages, evaluation rules, hardware and modalities. Then a second, independent Claude agent reviewed the plans for missing topics and ordering errors. It reported 48 findings, 5 of them critical, and all of them were fixed. A one-off script then checked that no module, in either plan, depends on or refers to a module placed after it.

**What blocked, and how it was solved.**
- A model small enough to train on my 8 GB GPU cannot reliably follow instructions or call tools, so I could not test the agent harness with it. Solution: my own engine loads published open-weight models and treats them as data. The code stays 100 % mine.
- The first draft taught image generation right after the Transformer, before a working text model existed. I reordered the LLM plan by fundamentality, and images now come after every text extension.

**Decisions and reasons.**
- Python, C and CUDA: Python to understand each component, C and CUDA for speed.
- Evaluations are generated on the spot and never written in advance. The pass mark is 100 %.
- An exercise counts as already seen if it repeats an earlier statement, or if its answer could be recalled from memory. Each new evaluation therefore uses a new context and new values.
- TLS 1.3 is written by hand, so that even data downloads use no library.
- Every document is written in English, for international readers.

**Measurements.** 49 prerequisite modules and 70 LLM modules. 48 review findings fixed. No module depends on, or refers to, a later module in either plan.

**What I learned.** Ordering a curriculum by dependencies is harder than listing topics. The review found prerequisites that no module taught (reinforcement learning theory, formal languages and parsing), although later modules relied on them.

**Next step.** Write the detailed files of the LLM plan, then start stage 1 of the prerequisites: MA01, MA02, MA03, IN01, IN02 and ME01.
